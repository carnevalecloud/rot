# ROT

Portrait-first, turn-based first-person survival prototype using Babylon.js and TypeScript.

## Run

```bash
npm install
npm run dev
```

W/Up: forward, S/Down: back, A/D: turn 90 degrees, Q/E: strafe, F: interact, Space: wait. Touch controls are always available on mobile.

Features: discrete grid movement, short camera animations, procedural low-poly pixel-textured scene, zombie turn AI, doors, item pickup, status HUD, action log, responsive portrait controls, and local save/load.
